# Screenshots and Demo Assets

This folder is reserved for portfolio screenshots captured from the running PriceFinder BD app. No screenshots are included yet because the application has not been visually run and captured in this workspace.

## Recommended screenshots

Capture clean screenshots using sample data only, then add them to this folder with these filenames:

1. `01-product-search.png` — catalog search and category filters.
2. `02-barcode-scanner.png` — scanner screen (do not include personal data).
3. `03-price-comparison.png` — compare prices for one exact product variant.
4. `04-nearby-shops.png` — nearby shop list and distance.
5. `05-shopkeeper-portal.png` — listing management view.
6. `06-ai-identification.png` — image selection and confirmation flow.
7. `07-api-docs.png` — FastAPI Swagger UI at `/docs`.

## Capture guidelines

- Use sample/test records, never real customer information.
- Hide device notifications, account emails, API keys, access tokens and local network details.
- Do not label sample prices as live or verified retailer prices.
- If recording a demo, show the complete user flow and mention which integrations use sample data or need configuration.
- After adding images, link them from the root README using relative paths, for example: `![Price comparison](docs/screenshots/03-price-comparison.png)`.
